# SKILLS.md

Этот файл является индексом навыков для человека. Он оставлен в корне проекта как справка.

Важно: opencode загружает skills не из этого файла, а из файлов `SKILL.md` в папках `.opencode/skills/<name>/`.

## Настроенные skills

| Skill | Файл | Когда использовать |
| --- | --- | --- |
| `product-spec` | `.opencode/skills/product-spec/SKILL.md` | Когда нужно подготовить или уточнить техническое задание, MVP, пользовательские сценарии и критерии приемки |
| `implementation-plan` | `.opencode/skills/implementation-plan/SKILL.md` | Когда нужно разложить согласованное ТЗ на этапы реализации до написания кода |
| `quality-gate` | `.opencode/skills/quality-gate/SKILL.md` | Когда нужно проверить готовность результата перед финальным ответом |

## Правила opencode для skills

- Каждый skill лежит в отдельной папке `.opencode/skills/<name>/`.
- Внутри папки должен быть файл `SKILL.md` именно с таким именем.
- `SKILL.md` начинается с YAML-заголовка.
- Обязательные поля: `name` и `description`.
- `name` должен совпадать с именем папки.
- Имя skill использует строчные буквы, цифры и дефисы.

## Как просить агента использовать skill

```text
Подготовь техническое задание для приложения "Менеджер задач с ИИ". Если подходит skill product-spec, используй его. Код пока не создавай.
```

```text
Разложи согласованное ТЗ на план реализации. Если подходит skill implementation-plan, используй его. Не создавай файлы приложения без отдельного разрешения.
```

```text
Проверь готовность результата перед финальным ответом. Если подходит skill quality-gate, используй его.
```
